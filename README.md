# Tarot Daily Card - Telegram Mini App

A beautiful Telegram Mini App that provides daily AI-generated Tarot readings with a modern, luxurious gold aesthetic.

## Features

### Daily Card Generation
- **One Card Per Day**: Users receive a unique Tarot card reading every day
- **Moscow Timezone (9 AM MSK) Reset**: New card becomes available at 9:00 AM Moscow time
- **78 Rider-Waite Cards**: Complete Major and Minor Arcana deck
- **AI-Powered Interpretations**: Personalized readings generated by GPT-4

### AI Generation Engine
- **Text Interpretation**: Four-part reading with General Energy, Love & Relationships, Career & Finance, and Expert's Wisdom
- **DALL-E 3 Images**: Unique, high-quality card illustrations in golden mystical style
- **Expert Knowledge Base**: Customizable context from uploaded transcripts to shape the interpretation style

### Beautiful UI/UX
- **Light Gold Luxury Theme**: Modern, bright, premium aesthetic
- **3D Card Flip Animation**: Smooth CSS animation for card reveal
- **Mobile-First Design**: Optimized for Telegram Mini App experience
- **Haptic Feedback**: Vibration on successful card generation

### Sharing
- **Share to Story**: Integrated with Telegram's story sharing feature
- **Social Engagement**: Track shares for each generation

### Admin Panel
- **Statistics Dashboard**: Total users, generations, shares, top cards
- **User Management**: View all registered users
- **Generation Editor**: Manually edit text or image for any generation
- **Expert Context Manager**: Upload and manage knowledge base transcripts

## Tech Stack

- **Frontend**: React 18 with vanilla CSS
- **Backend**: Node.js + Express
- **Database**: PostgreSQL
- **AI**: OpenAI GPT-4 + DALL-E 3
- **Integration**: Telegram Web App API

## Quick Start

### 1. Prerequisites
- Node.js 18+
- PostgreSQL 14+
- Telegram Bot (from @BotFather)
- OpenAI API key

### 2. Installation

```bash
# Clone the repository
git clone <repository-url>
cd tarot-mini-app

# Install dependencies
npm install

# Copy environment file
cp .env.example .env
# Edit .env with your values

# Initialize database
psql -d your_database -f database_schema.sql

# Start the server
npm run dev
```

### 3. Environment Variables

```env
# Server
PORT=3000
NODE_ENV=development

# Database
DATABASE_URL=postgresql://user:pass@localhost:5432/tarot_app

# Auth
JWT_SECRET=your-secret-key
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your-password
ADMIN_TELEGRAM_IDS=123456789

# Telegram
TELEGRAM_BOT_TOKEN=your-bot-token

# OpenAI
OPENAI_API_KEY=sk-your-api-key
OPENAI_MODEL=gpt-4-turbo-preview
```

### 4. Telegram Bot Setup

1. Create a bot with @BotFather
2. Enable Mini App: Bot Settings -> Menu Button -> Configure
3. Set your app URL (e.g., `https://your-domain.com`)

## API Endpoints

### Public
- `POST /api/users/register` - Register/update user
- `GET /api/generations/today/:telegramId` - Check today's generation
- `POST /api/generations/generate` - Generate daily card
- `POST /api/generations/share` - Track share

### Admin (JWT Required)
- `POST /api/admin/login` - Admin login
- `GET /api/admin/verify` - Verify token
- `GET /api/admin/statistics` - Get statistics
- `GET /api/admin/users` - List users
- `GET /api/admin/generations` - List generations
- `PUT /api/admin/generations/:id` - Edit generation
- `GET /api/admin/expert-context` - List expert contexts
- `POST /api/admin/expert-context` - Add context
- `DELETE /api/admin/expert-context/:id` - Delete context

## Moscow Timezone Logic

The app uses a special "astronomical day" concept:
- Reset happens at **9:00 AM Moscow Time (UTC+3)** every day
- If a user requests a card at 8:00 AM MSK, they get the previous day's cycle
- If they request at 10:00 AM MSK, they enter the new day's cycle
- This ensures fair distribution regardless of when users open the app

## Expert Context (Knowledge Base)

To personalize AI interpretations in your expert's style:

1. Go to Admin Panel -> Expert Context
2. Click "Add Context"
3. Paste YouTube transcript or other text
4. Select category (general, love, career, spiritual)
5. Save

The AI will incorporate this knowledge into all future interpretations.

## Database Schema

### Core Tables
- **users**: Telegram users with generation counts
- **generations**: Daily card generations with AI content
- **tarot_cards**: 78 Rider-Waite cards with descriptions
- **expert_context**: Knowledge base transcripts
- **admin_users**: Admin accounts
