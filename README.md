# Telegram Mini App - Каталог Экспертов Таро 🔮

## О проекте

Это приложение представляет собой профессиональный каталог тарологов, интегрированный в Telegram через Mini App. Приложение создано специально для продвижения выпускников вашей школы таро и помогает соединять клиентов с квалифицированными специалистами. Система работает как витрина ваших учеников, повышая ценность обучения в школе за счет предоставления реальной возможности практики и заработка.

## Основные возможности

### Для клиентов:
- **Просмотр каталога экспертов** - удобный интерфейс с фотографиями и описаниями специалистов
- **Фильтрация по специализации** - быстрый поиск таролога под конкретный запрос (отношения, карьера, духовное развитие)
- **Сортировка по рейтингу и цене** - выбор оптимального специалиста по соотношению цена/качество
- **Детальные профили тарологов** - информация об образовании, опыте, философии работы
- **Система отзывов** - реальные отзывы от других клиентов для принятия решения
- **Безопасная запись на консультацию** - система кодов подтверждения для защиты от мошенничества
- **Образовательный блог** - полезные статьи о таро и развитии

### Для тарологов:
- **Профессиональный профиль** - возможность красиво презентовать себя потенциальным клиентам
- **Автоматические уведомления** - мгновенное оповещение о новых заявках через Telegram
- **Защита репутации** - модерация отзывов и возможность ответа на них
- **Статистика консультаций** - отслеживание количества клиентов и среднего рейтинга
- **Продвижение через "Таролог недели"** - дополнительная видимость для активных специалистов

### Для администраторов школы:
- **Полная админ-панель** - управление всеми аспектами приложения из одного места
- **Управление тарологами** - добавление, редактирование, активация/деактивация профилей
- **Модерация отзывов** - контроль качества обратной связи
- **Рекламные баннеры** - продвижение вебинаров и курсов школы
- **Детальная аналитика** - статистика посещаемости, популярности тарологов, конверсии
- **Управление блогом** - публикация образовательного контента

## Архитектура приложения

Приложение построено по классической трехуровневой архитектуре, где каждый уровень отвечает за свою область ответственности:

### Frontend (Клиентская часть)
- **React 18** - современный фреймворк для построения интерфейсов
- **Telegram Web App API** - глубокая интеграция с Telegram для нативного опыта
- **Адаптивный дизайн** - оптимизация под мобильные устройства
- **Компонентная архитектура** - переиспользуемые элементы интерфейса

### Backend (Серверная часть)  
- **Node.js + Express** - быстрый и масштабируемый сервер
- **JWT авторизация** - безопасная аутентификация администраторов
- **RESTful API** - стандартизированные эндпоинты для всех операций
- **Telegram Bot API** - отправка уведомлений и взаимодействие с пользователями

### Database (База данных)
- **PostgreSQL** - надежная реляционная база данных
- **Оптимизированная схема** - индексы для быстрых запросов
- **Автоматические триггеры** - обновление временных меток и статистики
- **Резервное копирование** - защита данных от потери

## Быстрый старт

Чтобы запустить приложение локально для разработки, выполните следующие шаги:

### 1. Клонирование репозитория
```bash
git clone <your-repository-url>
cd tarot-mini-app
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка базы данных
```bash
# Создайте базу данных PostgreSQL
createdb tarot_app

# Примените схему базы данных
psql -U postgres -d tarot_app -f database_schema.sql
```

### 4. Настройка переменных окружения
```bash
# Скопируйте пример файла
cp .env.example .env

# Отредактируйте .env файл и добавьте ваши настройки:
# - TELEGRAM_BOT_TOKEN от @BotFather
# - DATABASE_URL для подключения к PostgreSQL
# - JWT_SECRET для безопасности
# - Другие необходимые переменные
```

### 5. Запуск сервера разработки
```bash
npm run dev
```

Приложение будет доступно по адресу http://localhost:3000

## API Endpoints

Приложение предоставляет следующие API эндпоинты для взаимодействия:

### Публичные эндпоинты (доступны всем):

#### GET /api/tarot-readers
Получение списка всех активных тарологов с базовой статистикой
- Возвращает: массив объектов тарологов
- Фильтры: specialization, price_range
- Сортировка: rating, price, consultations_count

#### GET /api/tarot-readers/:id
Получение детальной информации о конкретном тарологе
- Параметры: id таролога
- Возвращает: полный профиль с отзывами

#### POST /api/consultations
Создание заявки на консультацию
- Тело запроса: tarot_reader_id, client_telegram_id, client_name, consultation_topic
- Возвращает: confirmation_code для подтверждения

#### POST /api/reviews
Добавление отзыва после консультации
- Тело запроса: consultation_id, rating, comment
- Требует: завершенную консультацию

### Административные эндпоинты (требуют авторизации):

#### POST /api/admin/login
Авторизация администратора
- Тело запроса: username, password
- Возвращает: JWT токен

#### GET /api/admin/statistics
Получение статистики приложения
- Возвращает: общую статистику и топ тарологов

#### POST /api/admin/tarot-readers
Добавление нового таролога
- Тело запроса: полная информация о тарологе
- Требует: админские права

#### PUT /api/admin/tarot-readers/:id
Обновление информации о тарологе
- Параметры: id таролога
- Тело запроса: обновленные данные

## Безопасность

Приложение использует многоуровневую систему безопасности для защиты данных и предотвращения злоупотреблений:

### Защита данных:
- **Шифрование паролей** - использование bcrypt для хеширования
- **JWT токены** - безопасная авторизация без хранения сессий
- **HTTPS обязателен** - шифрование трафика между клиентом и сервером
- **Валидация входных данных** - защита от SQL инъекций и XSS атак

### Защита от мошенничества:
- **Коды подтверждения** - проверка реальности консультаций
- **Модерация отзывов** - контроль качества обратной связи
- **Ограничение частоты запросов** - защита от спама и DDoS

### Приватность:
- **Минимальный сбор данных** - только необходимая информация
- **Не храним платежные данные** - оплата происходит напрямую тарологу
- **Соответствие GDPR** - право на удаление данных по запросу
