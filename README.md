# Telegram Бот "Карта Дня" 🔮

Telegram-бот для ежедневных карт Таро Уэйта с системой удержания пользователей.

## Возможности

- 🃏 **Карта дня** — ежедневное послание Таро с советом
- 🔥 **Система страйков** — отслеживание регулярных посещений
- 🎮 **Мини-игра "Угадай карту"** — угадай карту по описанию
- 👥 **Реферальная система** — приглашай друзей
- 📤 **Шеринг** — делись картой в чатах
- 🔔 **Push-уведомления** — напоминания в 8:00

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <repo-url>
cd tarot-mini-app
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Настройте переменные окружения

```bash
cp .env.example .env
```

Отредактируйте `.env`:
- `BOT_TOKEN` — токен от @BotFather

### 4. Запустите бота

```bash
npm start
```

Для разработки с авто-перезапуском:
```bash
npm run dev
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `BOT_TOKEN` | Токен Telegram бота | — |
| `TIMEZONE` | Часовой пояс | Europe/Moscow |
| `DAILY_CARD_TIME` | Время уведомлений | 08:00 |

## База данных

Используется SQLite (файл `tarot.db` создаётся автоматически).

**Таблицы:**
- `users` — пользователи
- `daily_cards` — история карт
- `streaks` — страйки
- `game_scores` — результаты игры
- `referrals` — рефералы

## 78 карт Таро Уэйта

- 22 Старших Аркана

Каждая карта содержит:
- Название (рус/англ)
- Значение
