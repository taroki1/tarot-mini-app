# Инструкция по развертыванию Telegram Mini App для каталога тарологов

## Понимание архитектуры приложения

Прежде чем мы начнем развертывание, давайте разберемся, как устроено ваше приложение. Представьте его как трехэтажное здание, где каждый этаж выполняет свою функцию. На первом этаже находится база данных PostgreSQL - это фундамент, где хранится вся информация о тарологах, консультациях и отзывах. На втором этаже располагается серверная часть на Node.js - это мозг приложения, который обрабатывает все запросы и управляет логикой. И наконец, третий этаж - это интерфейс на React, то, что видят ваши пользователи в Telegram.

## Шаг 1: Подготовка Telegram Bot

Начнем с создания бота в Telegram, который станет точкой входа в ваше приложение. Этот процесс похож на регистрацию вашего бизнеса - вы получаете официальное "разрешение" от Telegram на работу с их платформой.

### Создание бота:
1. Откройте Telegram и найдите бота @BotFather - это официальный бот Telegram для создания других ботов
2. Отправьте ему команду `/newbot`
3. Придумайте имя для вашего бота, например: "Эксперты Таро Школы"
4. Создайте уникальное username для бота, оно должно заканчиваться на "bot", например: `TarotSchoolExpertsBot`
5. BotFather выдаст вам токен - это как ключ от вашего приложения. Сохраните его в надежном месте!

### Настройка Mini App:
1. В чате с BotFather введите команду `/mybots`
2. Выберите вашего созданного бота
3. Нажмите "Bot Settings" → "Menu Button"
4. Введите URL вашего приложения (пока можете указать временный, потом измените)
5. Введите название кнопки меню, например: "🔮 Каталог экспертов"

## Шаг 2: Настройка базы данных PostgreSQL

База данных - это сердце вашего приложения, где будет храниться вся информация. Я рекомендую начать с локальной установки для разработки, а затем перейти на облачный сервис для продакшена.

### Для локальной разработки:

#### Windows:
1. Скачайте PostgreSQL с официального сайта: https://www.postgresql.org/download/windows/
2. Запустите установщик и следуйте инструкциям
3. Запомните пароль для пользователя postgres - он понадобится для подключения
4. После установки откройте pgAdmin (устанавливается вместе с PostgreSQL)
5. Создайте новую базу данных с именем `tarot_app`

#### Mac:
```bash
# Установка через Homebrew - это менеджер пакетов для Mac
brew install postgresql
brew services start postgresql
createdb tarot_app
```

#### Linux:
```bash
# Для Ubuntu/Debian
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib
sudo -u postgres createdb tarot_app
```

### Создание структуры базы данных:

После создания базы данных, нужно создать все необходимые таблицы. Откройте терминал в папке проекта и выполните:

```bash
# Подключаемся к базе данных и выполняем SQL скрипт
psql -U postgres -d tarot_app -f database_schema.sql
```

Этот скрипт создаст все таблицы, индексы и начальные данные для вашего приложения.

### Для продакшена (рекомендуемые сервисы):

Для реального использования я рекомендую использовать облачную базу данных. Вот несколько хороших вариантов:

1. **Supabase** (бесплатный план включает 500MB):
   - Перейдите на https://supabase.com
   - Создайте новый проект
   - Скопируйте Database URL из настроек

2. **Railway** (простое развертывание):
   - Зарегистрируйтесь на https://railway.app
   - Создайте новый проект с PostgreSQL
   - Получите connection string

3. **Neon** (современный PostgreSQL):
   - Создайте аккаунт на https://neon.tech
   - Создайте базу данных
   - Скопируйте connection string

## Шаг 3: Настройка серверной части

Теперь давайте настроим серверную часть приложения. Это как настройка кухни в ресторане - здесь будут готовиться все "блюда" (данные) для ваших клиентов.

### Установка зависимостей:

```bash
# Переходим в папку проекта
cd tarot-mini-app

# Устанавливаем все необходимые пакеты
npm install

# Это установит все библиотеки, указанные в package.json
```

### Настройка переменных окружения:

```bash
# Копируем файл с примером настроек
cp .env.example .env

# Открываем файл .env в любом текстовом редакторе
# и заполняем реальными значениями
```

Вот что нужно обязательно заполнить в файле .env:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=postgresql://postgres:ваш_пароль@localhost:5432/tarot_app
JWT_SECRET=сгенерируйте_случайную_строку_32_символа
ADMIN_USERNAME=выберите_логин_админа
ADMIN_PASSWORD=придумайте_надежный_пароль
```

### Запуск сервера для разработки:

```bash
# Запускаем сервер с автоматической перезагрузкой при изменениях
npm run dev

# Вы должны увидеть сообщение:
# 🚀 Сервер запущен на порту 3000
# 📱 Telegram Mini App готово к работе!
```

## Шаг 4: Интеграция с Google Sheets (опционально)

Поскольку вы хотите управлять данными тарологов через Google Таблицы, давайте настроим интеграцию. Это позволит вам обновлять информацию о тарологах в привычном интерфейсе таблиц.

### Создание сервисного аккаунта Google:

1. Перейдите в Google Cloud Console: https://console.cloud.google.com/
2. Создайте новый проект или выберите существующий
3. Включите Google Sheets API:
   - В меню выберите "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и включите его
4. Создайте учетные данные:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "Service Account"
   - Заполните данные и создайте аккаунт
   - Создайте ключ в формате JSON и сохраните файл

### Настройка Google Таблицы:

1. Создайте новую Google Таблицу для управления тарологами
2. Поделитесь таблицей с email вашего сервисного аккаунта (с правами редактирования)
3. Структура таблицы должна быть следующей:

| Имя | Описание | Специализация | Ценовой диапазон | Telegram username | Пройденные курсы | Активен |
|-----|----------|---------------|------------------|-------------------|------------------|---------|
| ... | ...      | ...           | ...              | ...               | ...              | ...     |

### Создание скрипта синхронизации:

Я создам для вас скрипт, который будет синхронизировать данные между Google Sheets и вашей базой данных.

## Шаг 5: Развертывание в продакшен

Когда ваше приложение готово к реальному использованию, нужно разместить его на сервере. Вот несколько вариантов:

### Вариант 1: Vercel (рекомендуется для начала)

Vercel - это как готовая квартира со всей мебелью. Вам не нужно настраивать сервер, все работает из коробки:

1. Установите Vercel CLI:
```bash
npm install -g vercel
```

2. В корне проекта выполните:
```bash
vercel
```

3. Следуйте инструкциям в терминале
4. Добавьте переменные окружения в панели управления Vercel

### Вариант 2: Railway (все в одном)

Railway позволяет развернуть и базу данных, и приложение в одном месте:

1. Подключите ваш GitHub репозиторий к Railway
2. Добавьте сервис PostgreSQL
3. Добавьте сервис для вашего Node.js приложения
4. Настройте переменные окружения

### Вариант 3: VPS (полный контроль)

Если вы хотите полный контроль, арендуйте VPS (например, на Reg.ru или FirstVDS):

```bash
# На сервере Ubuntu:
# Установка Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# Установка PostgreSQL
sudo apt-get install postgresql

# Клонирование вашего проекта
git clone your-repo-url
cd tarot-mini-app

# Установка зависимостей
npm install

# Установка PM2 для управления процессом
npm install -g pm2

# Запуск приложения
pm2 start server.js --name tarot-app
pm2 save
pm2 startup
```

## Шаг 6: Подключение домена и SSL

Для профессионального вида вашему приложению нужен собственный домен:

1. Купите домен (например, на Reg.ru)
2. Настройте DNS записи на ваш сервер
3. Установите SSL сертификат для https (обязательно для Telegram Mini Apps!)

Для автоматической установки SSL используйте Certbot:
```bash
sudo apt-get install certbot
sudo certbot certonly --standalone -d your-domain.com
```

## Шаг 7: Финальная настройка Telegram Mini App

После развертывания вернитесь к @BotFather и обновите URL вашего Mini App:

1. Команда `/mybots`
2. Выберите вашего бота
3. Bot Settings → Menu Button → Edit Menu Button URL
4. Введите: `https://your-domain.com`

## Частые проблемы и их решения

### Проблема: "Cannot connect to database"
**Решение:** Проверьте DATABASE_URL в .env файле и убедитесь, что PostgreSQL запущен

### Проблема: "Telegram Bot Token is invalid"
**Решение:** Проверьте, правильно ли скопирован токен от BotFather

### Проблема: "Mini App не открывается в Telegram"
**Решение:** Убедитесь, что у вас настроен SSL сертификат (https обязателен!)
